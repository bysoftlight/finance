# softlight Finance

ระบบ One Stop ของ softlight สำหรับรวมทุกธุรกรรมการเงินไว้ที่เดียว — https://bysoftlight.github.io/finance/

| โมดูล | ทำอะไรได้ |
|---|---|
| **เอกสาร** | ใบเสนอราคา → ใบแจ้งหนี้ → ใบเสร็จ เลขที่รันต่อเนื่องแยกตามประเภทและปี (QT/INV/RC-2569-0001) · VAT 7% (รวม/ไม่รวมในราคา) · หัก ณ ที่จ่าย 1/2/3/5% · พิมพ์/บันทึก PDF ขนาด A4 · ยกเลิกเอกสารโดยเก็บเลขไว้ |
| **รับชำระ** | บันทึกการชำระทีละงวด (รวมยอดที่ลูกค้าหัก ณ ที่จ่าย) แล้วออกใบเสร็จอัตโนมัติ |
| **ลิงก์ให้ลูกค้า** | ส่งลิงก์ให้ลูกค้าเปิดดู/พิมพ์บิลได้ทันทีโดยไม่ต้องสมัคร · แก้เอกสารแล้วลิงก์อัปเดตตาม · ยกเลิกการแชร์ได้ |
| **Subscription** | ลูกค้ารายเดือน/รายปี เตือนเมื่อครบรอบ ออกใบแจ้งหนี้รอบถัดไปในคลิกเดียว |
| **ภาษี/รายงาน** | สรุปรายได้รายเดือนตามใบเสร็จ (เกณฑ์เงินสด) · ภาษีขาย · ภาษีที่ถูกหัก ณ ที่จ่าย · แยกตามหมวด (ซอฟต์แวร์ / ถ่ายภาพ / Subscription) · ส่งออก CSV เปิดใน Excel/Google Sheets |
| **ลูกค้า + รายการสินค้า/บริการ** | เก็บข้อมูลลูกค้า (เลขผู้เสียภาษี/สาขา) · แคตตาล็อกราคา HR Paper Mill และงานถ่ายภาพ แก้ราคาได้ |

ข้อมูลเก็บใน **Google Drive ของผู้ใช้เอง** (โฟลเดอร์ข้อมูลแอปที่ซ่อนไว้ ไม่รกไดรฟ์) ใช้ได้ทุกเครื่องที่เข้าสู่ระบบด้วยบัญชีเดียวกัน และยังใช้งานได้แม้ออฟไลน์ (บันทึกในเครื่องก่อนแล้วซิงก์ทีหลัง) · แก้จากหลายเครื่องพร้อมกันระบบจะรวมให้ (รายการที่แก้ล่าสุดชนะ) ไม่เขียนทับทั้งไฟล์

ใบเสนอราคาจากโปรแกรมเดิม (bysoftlight.github.io/quotation) นำเข้าได้ในคลิกเดียว — แอปจะแสดงปุ่มให้เองถ้าเจอในเครื่อง

## ตั้งค่า Google (ทำครั้งเดียว ~10 นาที)

1. เปิด https://console.cloud.google.com/ → สร้างโปรเจกต์ (หรือใช้โปรเจกต์ของ HR Paper Mill)
2. **APIs & Services → Library** → เปิด **Google Drive API**
3. **OAuth consent screen** → User type: External → ใส่ชื่อแอป "softlight Finance" และอีเมล
   → Scopes: เพิ่ม `.../auth/drive.appdata` และ `.../auth/drive.file` (ทั้งสองเป็น scope ที่ไม่ต้องให้ Google ตรวจแอป)
   → **Publish app** (หรือเพิ่มอีเมลตัวเองใน Test users ถ้ายังไม่ publish)
4. **Credentials → Create credentials → OAuth client ID** → Application type: **Web application**
   → Authorized JavaScript origins: `https://bysoftlight.github.io` → คัดลอก **Client ID**
5. **Credentials → Create credentials → API key** → Edit API key:
   → Application restrictions: Websites → `https://bysoftlight.github.io/*`
   → API restrictions: Restrict key → **Google Drive API** → คัดลอก **API key**
6. ใส่ทั้งสองค่าใน `js/config.js` (หรือทดลองก่อนในแอป: ตั้งค่า → บัญชี Google → ค่าเชื่อมต่อ)

API key ใช้เฉพาะหน้า `view.html` ให้ลูกค้าอ่านไฟล์บิลที่แชร์แบบ "ทุกคนที่มีลิงก์" — อ่านได้เฉพาะไฟล์ที่ตั้งเป็นสาธารณะเท่านั้น

## ไฟล์

- `index.html` · `js/app.js` — หน้าจอทั้งหมด
- `js/core.js` — คำนวณยอด/VAT/หัก ณ ที่จ่าย · ตัวอักษรจำนวนเงิน · แสดงเอกสาร A4 (ใช้ร่วมกับหน้าลูกค้า)
- `js/store.js` — ข้อมูล + ซิงก์ Google Drive + เลขที่เอกสาร + นำเข้าจากโปรแกรมเดิม
- `js/drive.js` — เข้าสู่ระบบ Google + Google Drive API
- `js/catalog.js` — รายการสินค้า/บริการตั้งต้น และหมายเหตุเริ่มต้น
- `view.html` — หน้าดูบิลของลูกค้า (`view.html#<fileId>`)

ดีไซน์ชุดเดียวกับ HR Paper Mill (Material 3, โหมดมืด, ใช้ได้ทุกขนาดจอ)
